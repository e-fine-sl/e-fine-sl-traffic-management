## 🚀 Quick Start: How to View & Use

### Method 1: Local Interactive Figma Workbench App
1. Open the [wireframes/index.html](file:///d:/Final_Year_Project/Final_Year_Project_e-Fine_SL/wireframes/index.html) file in any web browser (Google Chrome, Microsoft Edge, Firefox, Brave).
2. Use the left navigation sidebar to switch between **Driver Mobile App**, **Police Duty Portal**, and **Super Admin Dashboard**.
3. View crisp, full-screen vector artboards framed inside mobile devices without any overlay options or zoom buttons.

---

### Method 2: Import Direct into Figma (Drag-and-Drop)
All `.svg` files in the `wireframes/svg/` folder are native vector artboards:

1. Open your **Figma** desktop app or go to [figma.com](https://figma.com).
2. Create a new Figma Design file.
3. Open your computer's file explorer and navigate to `d:\Final_Year_Project\Final_Year_Project_e-Fine_SL\wireframes\svg`.
4. **Drag and drop** any `.svg` file directly onto the Figma canvas!
5. Figma will automatically convert all elements into **editable Figma Frames, Vector Shapes, Text Layers, and Colors**!
